# 教研设计模板与案例

> 教研设计是839历年必考题型（2020-2025每年都有）。2023年起设计题变为教案设计为主，但论述题第二题常涉及教研设计。本文件备用，当前优先做教案设计。

---

## 一、教育研究概述

### 含义
教育研究是指运用科学的研究方法，遵循一定的研究原则和程序，对于教育现象、问题进行探索，揭示教育的本质属性以及规律的活动过程。

- **对象**：教育现象、教育问题
- **功能**：描述（what）→ 解释（why）→ 预测（will）→ 控制（how）
- **意义**：1. 改进教育实践；2. 推进理论建设；3. 促进教师发展

### 研究流程（10步）
1. 提出问题（理论性课题/实践性课题/各种科研项目）
2. 文献综述（对以往相关主题文献进行综合论述，确定研究问题、价值、思路）
3. 确定问题（根据文献综述确定具体、切实可行的研究问题）
4. 提出假设（结合理论分析与实践经验，对变量关系进行假设）
5. 确定研究对象（明确总体、抽样方法以及样本）
6. 确定研究方法（选择合适、可行的研究方法）
7. 具体研究设计（结合不同研究方法的思路进行设计）
8. 实施研究（在教育实践中实施研究计划）
9. 收集整理分析资料
10. 结果解释，形成结论

## 二、教研设计模板（八环节）

| 环节 | 具体内容 |
|---|---|
| 一、研究背景与意义 | 1. 研究背景：政策、现状、问题<br>2. 研究意义：完善理论、改善实践、提升教师水平 |
| 二、研究问题 | 考试一般给开放性主题，需自行设计具体问题。注意具体、明确 |
| 三、提出假设 | 针对研究问题，结合理论和实际，给出合理假设。实验研究必有；观察/调查视情况；行动研究一般无 |
| 四、研究方法 | 观察研究法、调查研究法、实验研究法、行动研究法（任选其一或其二） |
| 五、研究对象 | 运用（抽样方法），在（总体）中选取样本（N）人 |
| 六、具体研究设计 | 按所选研究方法的设计格式展开 |
| 七、收集、整理与分析资料 | 对研究资料进行收集、整理，采取相关方法分析 |
| 八、结果解释，形成结论 | 若……（结果），则说明……（结论） |
| 研究反思（选） | 1. 本研究设计的优点<br>2. 局限性和未来改进 |

## 三、提出假设

### 假设的含义
对所研究问题的规律或原因做出的推测性论断和假定性说明。

### 假设涉及的变量

| 变量类型 | 含义 | 操作 |
|---|---|---|
| 自变量 | 研究者主动操纵而变化的变量 | 操控 |
| 因变量 | 通过自变量的变化而产生变化的结果变量 | 观测 |
| 无关变量 | 除自变量以外一切可以影响因变量的变量（控制变量） | 控制 |

### 规范假设的要求
1. 阐明关系：自变量、因变量及其之间的关系要明确
2. 有理有据：有充分的理论和事实依据
3. 可以检验：自变量能够操作，因变量能够观测

### 假设示例
- "开放型的课堂有利于学生主体性的发展"（自变量：开放性课堂；因变量：学生主体性发展）
- "课后作业的布置有利于提升学生学习成绩"（自变量：课后作业布置；因变量：学生学习成绩）

### 不同研究方法的假设要求

| 研究方法 | 是否需要假设 |
|---|---|
| 实验研究 | **必有**，要写清自变量与因变量的关系 |
| 观察研究 | 视情况：若研究现状/发展情况则无；若研究变量关系则有 |
| 调查研究 | 视情况：同上 |
| 行动研究 | 一般没有，可换成"具体分析" |

## 四、抽样方法

| 方法 | 含义 | 适用 | 举例 |
|---|---|---|---|
| 简单随机抽样 | 以随机原则为依据的最基本抽样方法。抽签/随机数目表 | 总体异质性不大，样本数较小 | 60人中随机选5人 |
| 系统随机取样 | 也叫等距抽样，按一定间隔在总体中抽取样本 | 总体异质性不大，样本数较大 | 1000人中等距选择100人 |
| 分层随机抽样 | 按照总体不同类别比例来进行抽样 | 总体异质性较强 | 初中500+300+200人，按比例抽100人 |
| 整群随机抽样 | 抽样单位是群体（如班级），而非个体 | 总体异质性不大，以群体为单位 | 在初二20个班中随机选2个班 |

抽样基本要求：明确总体、随机取样、代表总体、合理容量。

## 五、四种研究方法

### 1. 观察研究法

| 项目 | 内容 |
|---|---|
| 含义 | 通过感官或借助一定仪器，有计划地观察教育情境中的教育现象，从而搜集资料并对其分析总结 |
| 特点 | 自然性 |
| 在实践中的工具 | 观察记录表（定量）、观察提纲（定性） |
| 举例 | 观察王老师课上学生们的表现情况 |

### 2. 调查研究法

| 项目 | 内容 |
|---|---|
| 含义 | 通过对教育事实的考察、现状的了解、材料的收集来认识教育现象 |
| 特点 | 样本多、范围广、便分析 |
| 在实践中的工具 | 问卷法、访谈法、测量法 |
| 举例 | 调查学生对教师教学的满意度 |

### 3. 实验研究法

| 项目 | 内容 |
|---|---|
| 含义 | 运用科学实验的原理和具体方法来研究教育研究现象和问题 |
| 特点 | 重因果、能控制（操控自变量、观测因变量、控制无关变量） |
| 举例 | 不同的教学方法对学生学习表现的影响 |

**实验设计格式：**

| 设计类型 | 格式 | 说明 |
|---|---|---|
| 单组前后测设计 | G: O1 X O2 | 只有一个实验组，有前测和后测 |
| 非随机分派控制组前后测 | G1: O1 X O2<br>G2: O3 O4 | 有实验组和对照组，非随机分派 |
| 随机分派控制组后测 | RG1: X O1<br>RG2: C O2 | 随机分派，只有后测 |
| 随机分派控制组前后测 | RG1: O1 X O2<br>RG2: O3 C O4 | 随机分派，有前后测，最严谨 |

符号说明：G=组，R=随机分派，X=实验处理，C=对照处理，O=观测（测试）

### 4. 行动研究法

| 项目 | 内容 |
|---|---|
| 含义 | 行动者为了改进自己的实践而在自己的行动中亲自展开研究 |
| 特点 | 实践性 |
| 流程 | 计划→行动→观察→反思（至少两轮） |
| 举例 | 王老师运用行动研究在自己的课堂上不断提升学生学习动机 |

**行动研究具体设计格式：**

```
第一轮：
  计划1：发现问题；寻找方案；制定计划
  行动1：按照计划实施行动
  观察1：通过多种方式、多角度观察行动效果
  反思1：对行动进行评价与解释，为下一轮铺垫

第二轮：
  计划2：（基于反思1修改计划）
  行动2：
  观察2：
  反思2：

第三轮：（视需要）
```

## 六、研究方法组合

- **调查研究+访谈**：问卷收集普遍现状，访谈深入探索分析
- **调查+实验**：调查用于实验前后的学生表现（动机、态度、行为等）
- **观察/调查+行动**：观察、调查用于发现现状问题；行动研究用于改善实践

## 七、完整案例

### 案例1：关于小学低年级不留家庭作业对数学成绩影响的实验研究

**一、研究背景与意义**
为了深入贯彻落实双减政策，进一步减轻学生课业负担，北师大附属小学计划制定"小学低年级不留家庭作业的政策"。本研究采取实验研究法，探究在数学学科中，小学低年级不留家庭作业对学生数学成绩的影响，以便完善家庭作业设计理论，改善实践困境，落实减负细则。

**五、研究对象**
运用整群随机抽样，在初二共20个班级中，选取2个班，一个作为实验班，一个作为对照班。

**六、具体研究设计（实验格式）**
非随机分派控制组前后测：
- G1（实验组）: O1 X O2
- G2（对照组）: O3 O4
- X：取消数学家庭作业
- O1：实验组前测（取消前数学成绩）
- O2：实验组后测（取消后数学成绩）
- O3：对照组前测
- O4：对照组后测

变量说明：
- 操作自变量：实验组取消家庭作业；对照组正常布置家庭作业
- 观测因变量：通过难度适中的数学测试观测学生数学成绩
- 控制无关变量：同一教师教学、教学内容一致、考试难度一致等

**八、结果解释**
若取消数学家庭作业的小学生数学成绩明显高于（具有统计学意义）对照组，则说明"小学低年级不留家庭作业有助于学生数学学业成绩的提高"；反之，则说明"不利于学生数学学业成绩的提高"。

### 案例2：关于培养王老师班级内学生责任意识的行动研究

**一、研究背景与意义**
1. 研究背景：随着教育政策强调学生全面发展，"责任意识"成为核心素养要求之一。王老师班级内学生责任意识参差不齐，表现为责任感缺失、责任行为缺乏等问题，亟需改善。
2. 研究意义：本研究使用行动研究法，通过多轮研究，围绕学生责任意识的缺乏原因、培养措施进行深入探索，旨在完善责任意识培养的理论体系，为同类班级提供可借鉴的实践经验。

**三、提出假设**（行动研究一般无假设，换成"具体分析"）
①确定缺乏责任意识的成因；②设计培养学生责任感的综合实践活动；③整体反思，逐步完善。

**五、研究对象**
运用简单随机抽样，在王老师班级55名学生中，选取样本10人，进行访谈。

**六、具体研究设计**（行动研究，至少两轮）
第一轮：计划1→行动1→观察1→反思1
第二轮：计划2→行动2→观察2→反思2
