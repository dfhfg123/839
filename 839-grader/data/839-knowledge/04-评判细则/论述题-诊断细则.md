# 论述题 · 诊断细则（v1）

> **版本说明**：本细则为 v1 初始版本，基于北师大839知识手册中的答题框架、示范答案和历年真题反推得出。后续需通过浏览器搜集更多资料（高分答卷、专家点评、辅导机构评分标准等）持续迭代。
>
> **使用方式**：Agent 收到论述题答案后，先识别题目子类型，然后按对应维度的检查清单逐项诊断，最后输出结构化诊断报告。

---

## 一、通用诊断维度（适用于所有论述题）

### 维度1：结构完整性

检查答案是否具有清晰的"总—分—总"结构：

- [ ] **总起**：开头是否有总述/总观点（1-2句话点明核心立场）
- [ ] **分述**：主体部分是否分点展开（2-4个并列或递进的维度）
- [ ] **总结**：结尾是否有综合升华（回扣主题，提出启示/展望）
- [ ] **层次标记**：是否使用了清晰的分点标记（如"第一/第二"或"1. 2. 3."或"首先/其次/最后"）

**诊断标准**：
- 优秀：总-分-总完整，层次标记清晰，每点内部有"观点+论据+小结"的完整结构
- 良好：有总分总框架，但某层次内部展开不够
- 不足：缺少总起或总结，或分点混乱、逻辑跳跃

### 维度2：理论运用准确性

检查答案是否正确引用教育学理论：

- [ ] 是否引用了相关教学原则/方法/概念
- [ ] 引用的概念是否使用准确（未混淆近义概念，如"教学原则"与"教学方法"）
- [ ] 理论与论点之间的关联是否成立（非生搬硬套）
- [ ] 是否体现了"方法论+科学方法"的层级意识（而非笼统说"要因材施教"）

**诊断标准**：
- 优秀：准确引用2个以上相关理论概念，且理论与论点有机融合
- 良好：引用了相关理论，但关联不够紧密或有轻微不准确
- 不足：未引用理论，或引用错误

**参考理论库**：教学原则8条、教学方法10种、教学评价5维度、教学模式4种、德育原则6条、德育方法6种（详见03-理论基础/）

### 维度3：实践联系

检查答案是否联系实际：

- [ ] 是否结合了具体教学案例或教育现象
- [ ] 案例是否与论述主题直接相关（非泛泛而谈）
- [ ] 案例是否具体（有学科、有情境、有操作），而非抽象描述
- [ ] 是否联系了当前教育政策或热点（视题目要求）

**诊断标准**：
- 优秀：有2个以上具体案例，且案例与理论形成互证
- 良好：有案例但不够具体或与理论关联较弱
- 不足：纯理论空谈，无任何实际联系

**参考政策热点**：教育现代化2035、教育强国纲要、课标2022版、教育评价改革、AI教育指南、家庭教育促进法（详见06-政策热点.md）

### 维度4：学理深度

检查答案的思维层次：

- [ ] 是否超越了"是什么"的罗列，进入了"为什么"和"怎么做"的分析
- [ ] 是否有辩证思维（如"既…又…""一方面…另一方面…"）
- [ ] 是否触及了问题本质（而非停留在表面现象）
- [ ] 是否有个人见解或创新思考（而非纯背诵）

**诊断标准**：
- 优秀：有辩证分析+本质追问+个人见解，体现"是什么-为什么-怎么做"三层递进
- 良好：有"为什么"的分析，但辩证性或深度不够
- 不足：停留在"是什么"的罗列，无分析深度

### 维度5：语言表达

- [ ] 用词是否规范、学术化（避免口语化表达）
- [ ] 语句是否通顺、逻辑连贯
- [ ] 是否使用了教育学术语（如"主体性""最近发展区""核心素养"等）
- [ ] 篇幅是否适当（论述题一般800-1200字为宜）

**诊断标准**：
- 优秀：学术规范、术语准确、逻辑流畅、篇幅适当
- 良好：基本通顺，但偶有口语化或术语使用不当
- 不足：语言口语化、逻辑混乱、篇幅过短或过长

## 二、子类型专项诊断

### 子类型A：关系题（A与B的关系）

**触发条件**：题目要求论述两个概念的关系（如"智育与德育的关系""教育实践与教育理论的关系"）

**结构检查（对照模板）**：
- [ ] 含义界定：A的内涵 + B的内涵
- [ ] 相互联系：A→B的促进 + B→A的促进
- [ ] 相对独立：A的独特性 + B的独特性
- [ ] 辩证综合：缺一不可/二者不可偏废
- [ ] 总结升华：A+B→学生发展/教师进步/课程质量

**深度检查**：
- [ ] "A→B"的促进是否给出了机制性说明（而非断言"A促进B"）
- [ ] "相对独立"是否指出了A和B各自的不可替代性
- [ ] "缺一不可"是否说明了偏废的后果（只注重A则…，只注重B则…）

### 子类型B：观点评价题

**触发条件**：题目给出某种做法/观点，要求评价（如"某校要求每位教师都有独特教学模式，谈谈你的评价"）

**结构检查（对照模板）**：
- [ ] 是否明确表态（赞成/不赞成/部分赞成）
- [ ] 是否给出了理由（理论依据 + 事实依据）
- [ ] 若部分赞成：是否区分了可取之处与局限性
- [ ] 是否提出了正确做法/改进建议
- [ ] 是否有总结

**深度检查**：
- [ ] 表态是否有理有据（而非主观好恶）
- [ ] 评价是否多角度（从学生、教师、学校、课程等多主体）
- [ ] 是否体现了辩证思维（避免非黑即白）

### 子类型C：实际问题分析题

**触发条件**：题目给出教育情境/困境，要求分析问题并提建议（如"李老师班上学生水平差距大，分析困境并提建议"）

**结构检查（对照模板）**：
- [ ] 问题分析：是否准确识别了核心问题
- [ ] 原因分析：是否分析了问题产生的原因
- [ ] 对策建议：是否提出了具体可操作的解决措施
- [ ] 对策是否运用了"方法论+科学方法"思路（根据XX原则，使用XX法）
- [ ] 是否有总结

**深度检查**：
- [ ] 对策是否与问题一一对应（而非泛泛而谈）
- [ ] 对策是否具体可操作（有方法、有步骤），而非"要重视""要关注"
- [ ] 是否考虑了多主体协同（教师、学生、学校、家庭等）

### 子类型D：教学原理论述题

**触发条件**：题目要求论述某一教学原理（如"论述评价育人的教学原理""谈谈寓教于乐的教学原理"）

**结构检查**：
- [ ] 原理阐释：是否准确阐述了该原理的内涵
- [ ] 理论依据：是否说明了该原理的理论基础
- [ ] 实践应用：是否结合教学实际说明如何落实
- [ ] 意义价值：是否阐述了该原理的教育意义
- [ ] 总结升华

**深度检查**：
- [ ] 原理阐释是否完整（不仅说"是什么"，还说"为什么"和"怎么做"）
- [ ] 是否联系了相关教学原则/方法（如谈"评价育人"时联系"发展性评价"）
- [ ] 实践应用是否有具体案例支撑

### 子类型E：教育热点题

**触发条件**：题目涉及教育政策或热点（如"美育浸润活动的具体措施""家庭教育促进法"）

**结构检查（对照"是什么-为什么-怎么做"模板）**：
- [ ] 是什么：含义阐释（定性 + 围绕关键词展开）
- [ ] 为什么：必要性（现状有问题）+ 重要性（做完有好处）
- [ ] 怎么做：具体措施（按主体逻辑或问题逻辑展开）
- [ ] 总结

**深度检查**：
- [ ] "怎么做"是否按主体逻辑展开（学生、教师、家庭、学校、社会、国家）
- [ ] 或按问题逻辑展开（先找问题，后措施一一对应）
- [ ] 是否体现了政策敏感度（联系课标、规划纲要等文件）

## 三、诊断输出格式

Agent 输出的诊断报告应包含以下结构：

```
## 诊断报告

### 题目类型识别
[子类型A/B/C/D/E] + 简要说明

### 逐维度诊断

#### 维度1：结构完整性
- 评级：[优秀/良好/不足]
- 诊断：[具体说明哪里好/哪里有问题]
- 建议：[如何改进]

#### 维度2：理论运用准确性
- 评级：[优秀/良好/不足]
- 已正确引用：[列出答案中用到的理论概念]
- 应引用但未引用：[列出相关但未提到的理论]
- 引用错误：[如有，指出错误]
- 建议：[如何改进]

#### 维度3：实践联系
- 评级：[优秀/良好/不足]
- 诊断：[具体说明]
- 建议：[如何改进]

#### 维度4：学理深度
- 评级：[优秀/良好/不足]
- 诊断：[具体说明]
- 建议：[如何改进]

#### 维度5：语言表达
- 评级：[优秀/良好/不足]
- 诊断：[具体说明]
- 建议：[如何改进]

### 子类型专项诊断
[按对应子类型的检查清单逐项标注 ✓/✗ + 说明]

### 总体评价
- 核心优点：[1-2点]
- 主要不足：[1-2点]
- 优先改进方向：[1-2点，按重要性排序]
```
