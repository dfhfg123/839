# 教案设计 · 诊断与评分细则（v2）

> **版本说明**：v2 新增 25 分制评分标准。基于北师大839知识手册中的教案设计模板、多学科案例和历年真题反推得出。2023-2025年连续考察教案设计，是839的核心题型。
>
> **使用方式**：Agent 收到教案设计答案后，先按"环节完整性"检查9个环节是否齐全，再逐环节按质量标准诊断，再按评分标准量化打分，最后输出结构化诊断与评分报告。

---

## 一、环节完整性检查

教案设计共9个环节（其中七、八为选做）。先做完整性扫描：

| 序号 | 环节 | 必做/选做 | ✓/✗ |
|---|---|---|---|
| 一 | 教学背景（教材分析+学情分析） | 必做 | |
| 二 | 教学目标 | 必做 | |
| 三 | 教学内容（重点+难点） | 必做 | |
| 四 | 教学方法 | 必做 | |
| 五 | 教学资源/媒体 | 必做 | |
| 六 | 教学程序（具体实施流程） | 必做 | |
| 七 | 教学环境（座位摆放等） | 选做 | |
| 八 | 板书设计 | 选做 | |
| 九 | 教学评价 | 必做 | |

**完整性诊断**：列出缺失环节，提示补全。若必做环节缺失，标记为"严重不足"。

## 二、逐环节质量诊断

### 环节一：教学背景

**检查清单**：
- [ ] **教材分析**：是否说明了该课与前后内容的联系（承上启下）
- [ ] **学情分析**：是否分析了学生已有知识和认知特点
- [ ] 学情分析是否具体（而非泛泛说"学生有一定基础"）
- [ ] 是否分析了学生可能的困难或误区

**诊断标准**：
- 优秀：教材分析准确指出知识前后衔接关系；学情分析结合具体学段特点，指出现有水平和潜在困难
- 良好：有教材分析和学情分析，但不够具体
- 不足：缺失其一，或分析空泛

**参考案例**：
> 小学一年级《数学（下册）》20以内的退位减法
> - 教材分析：一年级上学期学习了10以内的加减法、20以内的进位加……在此阶段，20以内的退位减就是学生的学习需求；又是今后学习多位数减法的基础。
> - 学情分析：学生能正确计算十几减9的题目，且方法多样，如数手指、画图等直观方法居多……但速度很慢，没有形成一定的计算技能。

### 环节二：教学目标

**检查清单**：
- [ ] 是否按"学科核心素养观"或"三维目标观"展开
- [ ] 目标数量是否为3-4点
- [ ] 每个目标是否标注了对应素养维度（如"语言能力：…""文化意识：…"）
- [ ] 目标是否具体可测（而非"培养能力"这种笼表述）
- [ ] 目标是否覆盖知识、能力、情感三个层面

**诊断标准**：
- 优秀：按核心素养展开3-4点，每点标注维度，具体可测，三维覆盖
- 良好：有目标但未标注维度，或某点不够具体
- 不足：目标笼统、数量不足、维度单一

**参考案例**：
> 初中八年级道德与法治
> 1. 健全人格：通过情景体验合作交流，逐步掌握与他人交往沟通的技能，践行尊重他人诚实守信等优秀品质。
> 2. 政治认同：了解世界文化的多样性和丰富性，尊重本国的文化和习俗，拥有民族自信心、自豪感。
> 3. 道德修养：通过参与集体活动，正确认识和处理个人和集体之间的关系，逐渐形成善于合作的个性品质。

### 环节三：教学内容

**检查清单**：
- [ ] 是否明确写了"重点"
- [ ] 是否明确写了"难点"
- [ ] 重点是否准确（本课最核心的知识或技能）
- [ ] 难点是否合理（学生最可能困难的地方）
- [ ] 重点和难点是否有区分（不是同一句话）

**诊断标准**：
- 优秀：重点难点准确且有区分，贴合学科和学段
- 良好：有重点难点但区分不够
- 不足：缺失重点或难点，或表述笼统

### 环节四：教学方法

**检查清单**：
- [ ] 是否列出了具体教学方法（如讲授法、讨论法、探究法等）
- [ ] 方法选择是否与教学目标匹配
- [ ] 方法选择是否与教学模式（环节六）一致
- [ ] 是否考虑了学科特点（如语文课常用朗读法、角色扮演法）

**诊断标准**：
- 优秀：方法选择有依据，与目标和模式匹配，体现学科特色
- 良好：列出了方法但匹配性不够
- 不足：方法选择与教学模式矛盾，或方法笼统

### 环节五：教学资源/媒体

**检查清单**：
- [ ] 是否列出了具体教学资源（教具、视频、图片、课件等）
- [ ] 资源是否服务于教学目标（非为用而用）
- [ ] 是否考虑了传统媒体与现代媒体的结合

**诊断标准**：
- 优秀：资源具体、适度、与目标匹配
- 良好：有资源但匹配性不够
- 不足：缺失或堆砌资源

### 环节六：教学程序（核心环节）

**检查清单**：
- [ ] 是否按某一教学模式展开（程序教学/探究教学/问题教学/合作学习）
- [ ] 是否分环节/步骤展开（如"环节一→环节二→…"）
- [ ] 每个环节是否说明了教师活动和学生活动
- [ ] 关键环节是否写了"设计意图"
- [ ] 是否体现了师生互动的具体流程
- [ ] 是否体现了题目要求的学习方式（如"自主学习""合作学习"）
- [ ] 流程是否完整（从导入到总结到作业）
- [ ] 时间分配是否合理

**诊断标准**：
- 优秀：按教学模式展开，分环节清晰，师生互动明确，关键环节有设计意图，体现题目要求的学习方式，流程完整
- 良好：有流程但环节不够清晰，或缺少设计意图
- 不足：流程混乱、缺失关键环节、无师生互动、未体现要求的学习方式

**特别注意**：
- 2023-2025年真题均要求"体现学生自主学习/合作学习"及"说明师生互动具体流程及其设计意图"
- 设计意图是加分项，说明教师"为什么这样设计"，体现教学反思能力

**参考案例**：
> 初中八年级历史《改革开放》
> 环节一：体验情景，预习思考——教师通过情景引入，让学生了解改革之前国家发展现状……
> 环节二：合作探究，理解知识——教师指导学生阅读课文内容，引导学生小组合作探究……
> 环节三：调查事件、展示交流——课前分组，让学生调查了解国有企业的情况……
> 环节四：合作探究、分析归纳——指导学生观看反映深圳对外开放巨大变化的视频……
> 环节五：总结课程、延伸升华——引导学生对改革开放深入思考，以小论文形式呈现。

### 环节七：教学环境（选做）

**检查清单**：
- [ ] 是否设计了座位摆放（如小组合作可用矩形、马蹄形）
- [ ] 环境设计是否与教学模式匹配

### 环节八：板书设计（选做）

**检查清单**：
- [ ] 是否有课堂板书设计
- [ ] 板书是否体现知识结构

### 环节九：教学评价

**检查清单**：
- [ ] 是否有随堂测试或课堂评价
- [ ] 是否有课后作业布置
- [ ] 作业是否区分必做和选做（分层）
- [ ] 评价是否体现多维度（who/when/way/what/why）
- [ ] 评价是否注重发展性（非唯分数）

**诊断标准**：
- 优秀：有随堂测试+分层作业，评价体现多维度和发展性
- 良好：有评价但维度单一
- 不足：缺失评价环节，或评价方式单一

## 三、整体质量维度

### 维度A：学科契合度

- [ ] 教案是否体现了该学科的核心素养（如语文：语言能力、文化意识、思维品质、学习能力）
- [ ] 教学内容是否符合该学科的知识特点
- [ ] 教学方法是否适合该学科（如语文常用朗读法、情境法；理科常用实验法、探究法）
- [ ] 是否有学科特色的评价方式

**诊断标准**：
- 优秀：全面体现学科特色，核心素养标注准确
- 良好：基本符合学科特点，但特色不够突出
- 不足：教案"去学科化"，换成任何学科都适用

### 维度B：学段适切性

- [ ] 教学目标是否符合该学段学生的认知发展水平
- [ ] 教学方法是否适合该学段（如小学不宜纯讲授，高中可增加探究深度）
- [ ] 教学内容深浅是否适当

### 维度C：逻辑一致性

- [ ] 教学目标→教学内容→教学方法→教学程序→教学评价，是否一脉相承
- [ ] 前面设定的目标，在程序中是否有对应的落实环节
- [ ] 评价是否检验了目标的达成

**诊断标准**：
- 优秀：目标-内容-方法-程序-评价五位一体，逻辑闭环
- 良好：基本一致，但某环节有断裂
- 不足：各环节割裂，目标和程序不对应

### 维度D：题目要求响应度

- [ ] 是否回应了题目所有要求（如"体现合作学习""说明设计意图""20分钟授课时间"）
- [ ] 是否在显著位置体现了题目特殊要求
- [ ] 授课时间设定是否与题目一致

## 五、评分标准（25 分制）

### 评分原则

采用**分维度扣分制**：从满分开始，逐项检查扣分点，每扣一分必须对应一个具体的、可在答案中定位的问题。禁止"整体印象打分"。

### 维度1：环节完整性（满分 4 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 缺 1 个必做环节（每个） | -1 | 教学背景、目标、内容、方法、媒体、程序、评价缺一扣 1 |
| 必做环节整体缺失 3 个以上 | 扣完为止 | 本维度最低 0 分 |

### 维度2：教学目标（满分 5 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 未按核心素养展开 | -2 | 是否标注了学科核心素养维度 |
| 目标不可测 | -1 | 目标是否具体可观测 |
| 维度单一 | -1 | 是否覆盖知识、能力、情感三个层面 |
| 数量不足 3 点 | -1 | 是否有 3-4 个教学目标 |

### 维度3：教学程序（满分 7 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 未按教学模式展开 | -2 | 是否选择了程序/探究/问题/合作等模式 |
| 无师生互动 | -2 | 是否说明了教师活动和学生活动 |
| 无设计意图 | -1.5 | 关键环节是否写了设计意图 |
| 流程不完整 | -1 | 从导入到总结到作业是否完整 |
| 时间分配不合理 | -0.5 | 各环节时间分配是否合理 |

### 维度4：学科契合度（满分 3 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 去学科化（换成任何学科都适用） | -3 | 教案是否体现学科特色 |
| 核心素养标注错误 | -1 | 学科核心素养是否准确 |
| 教学方法不适合学科 | -1 | 方法选择是否符合学科特点 |
| 评价方式无学科特色 | -1 | 评价是否体现学科特点 |

### 维度5：逻辑一致性（满分 3 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 目标-程序脱节 | -1.5 | 程序中是否有对应目标的落实环节 |
| 评价不呼应目标 | -1 | 评价是否检验了目标达成 |
| 方法与模式矛盾 | -0.5 | 教学方法与教学模式是否一致 |

### 维度6：题目响应度（满分 3 分）

| 扣分项 | 扣分值 | 检查方法 |
|---|---|---|
| 未回应特殊要求 | -2 | 是否体现了题型要求的特定学习方式等 |
| 授课时间不符 | -1 | 时间设定是否与题目一致 |
| 未体现指定学习方式 | -1 | 是否有自主学习/合作学习等指定环节 |

## 五、待补充项（v2迭代方向）

1. **学科核心素养库**：需补充各学科核心素养的具体内容（语文、数学、英语、道法、历史、地理、生物、化学、物理等），目前知识库仅有道德与法治和英语两个学科的完整标注
2. **优秀教案锚点**：需收集3-5份不同质量的教案设计答卷，标注各环节等级，作为诊断参照
3. **历年教案真题专项分析**：2023-2025年教案设计题的要求差异分析（自主学习vs合作学习vs主题活动设计）
4. **北师大导师偏好**：搜集北师大语文学科教学论方向导师对教案设计的评价偏好
5. **时间分配参考**：20分钟微课教案的时间分配标准（各环节建议时长比例）
6. **主题活动设计要素**：2025年真题要求"主题活动设计"，需补充主题活动设计的基本要素与教案设计的差异
