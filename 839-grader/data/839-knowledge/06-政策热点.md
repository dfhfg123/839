## 一、中国教育现代化2035

### 总体目标
到2035年，总体实现教育现代化，迈入教育强国行列，推动我国成为学习大国、人力资源强国和人才强国，为到本世纪中叶建成富强民主文明和谐美丽的社会主义现代化强国奠定坚实基础。

### 具体目标
1. 学前：普及有质量的学前教育
2. 义务：实现优质均衡的义务教育
3. 普及：全面普及高中阶段教育
4. 职业：职业教育服务能力显著提升
5. 高等：高等教育竞争力明显提升
6. 特殊：残疾儿童少年享有适合的教育
7. 教师：建设高素质专业化创新型教师队伍
8. 信息：加快信息化时代教育变革
9. 国际：开创教育对外开放新格局
10. 治理：推进教育治理体系和治理能力现代化

### 战略任务
1. 思想：学习习近平新时代中国特色社会主义思想
2. 优质：发展中国特色世界先进水平的优质教育
3. 普及：推动各级教育高水平高质量普及
4. 均等：实现基本公共教育服务均等化
5. 终身：构建服务全民的终身学习体系
6. 高等：提升一流人才培养与创新能力
7. 教师：建设高素质专业化创新型教师队伍
8. 信息：加快信息化时代教育变革
9. 治理：形成全社会共同参与的教育治理新格局

### 答题思路
可从教育学原理各角度展开：教育学、教育、教育与人的发展、教育与社会发展、教育目的、教育制度、课程、教学、德育、教师、师生关系。

## 二、教育强国建设规划纲要（2024-2035年）

发布时间：2025年1月

### 意义
更好发挥教育强国建设在全面推进强国建设、民族复兴伟业中的先导任务、坚实基础、战略支撑作用。

### 目标（两步走）
- **第一步**（到2027年）：开局起步阶段，全方位打牢教育强国建设基础
- **第二步**（到2035年）：中长期，深化重大战略布局，确保如期建成教育强国

### 内容与要求

**三大属性**：教育的政治属性、人民属性、战略属性

**六大特质**：教育强国应当具有强大的思政引领力、人才竞争力、科技支撑力、民生保障力、社会协同力、国际影响力

**八大体系**：
1. 固本铸魂的思想政治教育体系
2. 公平优质的基础教育体系
3. 自强卓越的高等教育体系
4. 产教融合的职业教育体系
5. 泛在可及的终身教育体系
6. 创新牵引的科技支撑体系
7. 素质精良的教师队伍体系
8. 开放互鉴的国际合作体系

**五个重大关系**：
1. 支撑国家战略和满足民生需求
2. 知识学习和全面发展
3. 培养人才和满足社会需要
4. 规范有序和激发活力
5. 扎根中国大地和借鉴国际经验

## 三、义务教育课程方案与课程标准（2022年版）

### 课程方案主要变化

**1. 完善了培养目标**
全面落实习近平总书记关于培养担当民族复兴大任时代新人的要求，从有理想、有本领、有担当三个方面，明确义务教育阶段时代新人培养的具体要求。

**2. 优化了课程设置**
- 整合小学原品德与生活、品德与社会和初中原思想品德为"道德与法治"，进行九年一体化设计
- 改革艺术课程设置，一至七年级以音乐、美术为主线，融入舞蹈、戏剧、影视等内容，八至九年级分项选择开设
- 科学、综合实践活动开设起始年级提前至一年级
- 将劳动、信息科技及其所占课时从综合实践活动课程中独立出来

**3. 细化了实施要求**
- 增加课程标准编制与教材编写基本要求
- 明确省级教育行政部门和学校课程实施职责、制度规范，以及教学改革方向和改革重点
- 健全实施机制，强化监测与督导要求

### 课程标准主要变化

**1. 优化了课程内容结构**
- 基于核心素养要求，遴选重要观念、主题内容和基础知识技能
- 涉及同一内容主题的不同学科间，做好整体规划与分工协调
- 设立跨学科主题学习活动，加强学科间相互关联，带动课程综合化实施

**2. 研制了学业质量标准**
依据核心素养发展水平，明确"学到什么程度"，引导教师把握教学深度与广度，为教材编写、教学实施、考试评价等提供依据。

**3. 增强了指导性**
各课程标准针对"内容要求"提出"学业要求""教学提示"，细化评价与考试命题建议，注重实现教、学、考的一致性，强化"怎么教"的具体指导。

### 课程设置比例（关键数据）

| 课程类别 | 九年课时比例 |
|---|---|
| 道德与法治 | 6%~8% |
| 语文 | 20%~22% |
| 数学 | 13%~15% |
| 外语 | 6%~8% |
| 体育与健康 | 10%~11% |
| 艺术 | 9%~11% |
| 科学（或物理、化学、生物） | 8%~10% |
| 历史、地理 | 3%~4% |
| 信息科技 | 1%~3% |
| 劳动+综合实践活动 | 16%~20% |
| 地方与学校课程 | 14%~18% |

## 四、深化新时代教育评价改革总体方案

### 导向
以"五唯"（唯分数、唯升学、唯文凭、唯论文、唯帽子）为导向，以五类主体为抓手，着力做到政策系统集成、举措破立结合。

### 原因
中小学生学业压力过大，学校办学短视、功利，中小学过度重视考试分数和升学率，高校过度重视科研论文。为了完善正确导向，扭转不科学的教育评价导向，破除"五唯"痼疾，提高教育治理能力和水平。

### 措施（五类主体评价改革）

**1. 改革党委和政府教育工作评价**

**2. 改革学校评价**

**3. 改革教师评价**——推进践行教书育人使命
- 坚持把师德师风作为第一标准
- 突出教育教学实绩
- 强化一线学生工作
- 改进高校教师科研评价
- 推进人才称号回归学术性、荣誉性

**4. 改革学生评价**——促进德智体美劳全面发展
- 完善综合素质评价体系，树立科学成才观念
- 建立立德树人的评价标准，完善德育评价
- 强化体育评价
- 改进美育评价
- 加强劳动教育评价
- 严格学业标准
- 深化考试招生制度改革

**5. 改革用人评价**

### 意义
有利于深化教育领域综合改革；有利于全面提高教育治理能力和水平；有利于营造教育发展的良好生态；有利于建设教育强国、办好人民满意的教育。

## 五、北京市教育领域人工智能应用指南

来源：北京教育科学研究院、北京师范大学、北京智源人工智能研究院

### 含义
人工智能是指用机器模拟、实现和延伸人类的感知、思考、行动等智力与行为能力的科学与技术，包括自然语言处理、语音识别、图像识别和处理、情感检测、人工创作等。

### 意义
- 有利于积极适应智能时代发展趋势，响应国家"人工智能+"行动战略部署
- 有利于充分发挥人工智能在建设教育强国和构建首都高质量教育体系中的积极作用
- 有利于全面提升人工智能赋能首都教育的科学化、规范化水平

### 原则
1. **坚持立德树人**：以价值理性引导工具理性
2. **坚持公平优质**：实现优质教育资源的高效配置
3. **坚持融合创新**：人工智能技术与教育教学全过程深度融合
4. **坚持审慎包容**：评估和防范人工智能的伦理和社会风险
5. **坚持安全可靠**：数据安全和自主可控

### 六大应用方向

| 方向 | 具体内容 |
|---|---|
| 以"智"助教 | 教师备课、课堂管理、教学分析、学情分析、作业管理、答疑辅导、课程设计、教学辅助、跨学科主题学习辅助设计 |
| 以"智"助学 | AI学伴、语言学习助手、游戏化学习、情境式学习、智能辅导系统 |
| 以"智"助评 | "五育融合"学生画像、综合素质评价、学生评估、研究生学术评估 |
| 以"智"助育 | 智能阅读辅助、智能美育教育、智能体育健康、智能心理支持 |
| 以"智"助研 | 智能教师专业发展平台、智能科研实验平台 |
| 以"智"助管 | 学生信息智能管理 |

## 六、家庭教育促进法

### 是什么
指父母或者其他监护人对未成年人实施的道德品质、身体素质、生活技能、文化修养、行为习惯等方面的培育、引导和影响。

### 为什么
- 必要性：监管缺失/观念不当、方法不适，影响学生身心健康发展
- 重要性：保障家庭教育切实发挥教育和价值引领功能

### 怎么做
1. 明确责任：父母或其他监护人有对未成年人实施家庭教育的权利和义务
2. 禁止暴力：不得歧视，不得有任何形式的家庭暴力
3. 理念知识：树立正确的家庭教育理念，自觉学习家庭教育知识
4. 各方配合：明确各级政府、学校等主体在促进家庭教育方面的责任和义务

## 七、世界各国教育实践动态

### 总体发展趋势

**Way 1：**
1. 全民化：教育普及到每个人
2. 民主化：教育机会平等，打破特权
3. 信息化：利用互联网、大数据、人工智能提高教育效率和个性化
4. 全球化：加强国际交流与合作
5. 个性化：关注学习者个体差异
6. 终身化：教育贯穿人的一生

**Way 2：**
1. 增进教育公平（如英国《罗宾斯报告》推动高等教育扩招）
2. 健全法律法规（如德国构建职业教育法律保障）
3. 促进全面发展（如澳大利亚TAFE学院强调理论与实践并重）
4. 教师专业发展（如新加坡设立专业教师发展中心）
5. 强化评估机制（如美国数据驱动的教育评价系统）
6. 教育对接国际（如我国高校引进国际化教育模式）

### 世界各国课程改革发展趋势
1. 课程目标上，注重全面发展
2. 课程内容上，结合兴趣经验（内容本位→内容本位与能力本位相结合）
3. 课程结构上，丰富多样综合（新学科、跨学科课程、综合课程）
4. 课程实施上，强调学生主体（从"忠实取向"向"相互适应取向"与"创生取向"转换）
5. 课程评价上，过程发展评价（多主体、全方位、过程性、发展性、质和量相结合）
6. 课程管理上，三级管理体系（国家、地方、学校）

### 其他国家优秀教育实践

**美国：高等教育智能教育实践**
1. 先进教育理念引领：利用智能技术促进人的发展
2. 多方主体协同参与：自上而下与自下而上凝聚合力
3. 智能教育技术开发：自主研发与校企共建推动迭代升级
4. 组织结构深度变革：构建智能教育可持续发展的组织

**德国：全日制小学课后服务**
1. 科学性全面性：多元主体参与，注重学生全面发展
2. 维护教育公平：为学困生提供更多学习时间与辅导
3. 家庭事业平衡：帮助家长减轻负担
4. 个性全面发展：充分利用各种空间，促进身心发展
5. 教育创新文化建设：激励师生自发展开智能教育创新

**西方（英美）：博物馆教育**
1. 整合：跨学科资源整合，延展学校教育功能
2. 支持：集群生态打造，提供可持续专业支持
3. 实施：文娱活动融入，构建沉浸式教育场域
4. 信息：数字化技术赋能，突破教育时空壁垒
5. 政策：构建政策支持网络，夯实博物馆教育保障基础
