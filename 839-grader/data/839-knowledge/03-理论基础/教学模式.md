# 教学模式

> 教学模式是教学实践理论篇的重要内容。教案设计题中需要选择教学模式并按其流程展开教学程序。

## 一、四种主要教学模式

### 1. 程序教学

| 项目 | 内容 |
|---|---|
| 含义 | 以传授知识为主要目的，教师使用结构化的教学方式、有序的材料进行教学 |
| 过程 | 1. 复习温习 → 2. 教学引入 → 3. 讲授内容 → 4. 课堂练习 → 5. 评价总结 → 6. 作业布置 |
| 适用条件 | 讲授学生必须掌握的、结构良好的知识 |
| 举例 | 语文老师讲授"议论文"的写作方式 |

### 2. 探究教学

| 项目 | 内容 |
|---|---|
| 含义 | 学生仿照科学研究的过程自主学习科学知识，体验、理解和应用科学研究方法，获得科研能力的教学 |
| 过程 | 1. 提出问题 → 2. 收集信息 → 3. 探究行动 → 4. 结果展示 → 5. 评价总结 |
| 适用条件 | 探究性的学习任务 |
| 举例 | 在学习《大气压强》时，做瓶"吞"鸡蛋的实验 |

### 3. 问题教学

| 项目 | 内容 |
|---|---|
| 含义 | 以问题为线索，创设问题情境，激发学生自主学习的兴趣，在思维活动中掌握知识、发展智力、培养技能 |
| 过程 | 1. 提出问题 → 2. 思考交流 → 3. 形成观点 → 4. 交流汇报 → 5. 反思评价 |
| 适用条件 | 逐步引导学生深入思考学习，掌握知识与技能 |
| 举例 | 数学老师通过一步步提问，引导学生从长方形面积公式，推理出平行四边形面积公式 |

### 4. 合作学习

| 项目 | 内容 |
|---|---|
| 含义 | 能力各异的学生组成小组，以合作和互助的方式完成小组学习任务，促使每个个体增进学习水平，提高小组成绩 |
| 过程 | 1. 科学分组 → 2. 组内合作 → 3. 组间展示 → 4. 评价总结 |
| 适用条件 | 合作完成的任务 |
| 举例 | 小学科学课堂上大家以小组为单位做"飞得更远的纸飞机" |

---

## 二、教学模式选择依据

1. 教学目标：知识传授为主 → 程序教学；能力培养为主 → 探究/问题/合作
2. 教学内容性质：结构良好 → 程序；探究性 → 探究；合作性 → 合作
3. 学生特点：认知水平、年龄特点
4. 实际教学条件：时间、空间、资源

> 在教案设计中，可以选择单一模式，也可以混合使用。如"主要以小组合作学习展开，融入探究式教学"。
