# 教案设计模板与案例

> 2023-2025年连续考察教案设计，是839设计题的核心题型。

---

## 一、教案设计模板（九环节）

| 环节 | 具体内容 |
|---|---|
| 一、教学背景 | 1. 教材分析：说明该课与前后内容的关系<br>2. 学情分析：学生已有知识与认知特点 |
| 二、教学目标 | 按"学科核心素养观"或"三维目标观"展开，3-4点 |
| 三、教学内容 | 简写教学目标中出现的重点、难点 |
| 四、教学方法 | 讲授法、谈话法、讨论法、实验法、演示法、练习法、角色扮演法、情境模拟法等 |
| 五、教学媒体 | 教具、视频、图片、课件、生成式人工智能等 |
| 六、教学程序 | 按"程序教学""探究式教学""问题式教学""小组合作学习"等教学模式展开 |
| 七、教学环境（选） | 环境布置、座位摆放、空间设计 |
| 八、板书设计（选） | 课堂相关板书 |
| 九、教学评价 | 1. 随堂测试<br>2. 课后作业布置：必做作业 + 选做作业 |

## 二、各环节案例

### 教学背景案例

**案例1：小学一年级《数学（下册）》——20以内的退位减法**
1. 教材分析：一年级上学期学习了10以内的加减法、20以内的进位加、10加几、十几加几及相应的减法，并学会了利用相关知识解决求总数、求剩余的问题。在此阶段，20以内的退位减就是学生的学习需求；又是今后学习多位数减法的基础。
2. 学情分析：通过课前调查发现，学生能正确计算十几减9的题目，且方法多样，如数手指、画图等直观方法居多，还有部分学生进行自主探究，借助十几减10来推算十几减9，但速度很慢，没有形成一定的计算技能。因此，帮助学生自主探究算理，掌握又快又对的方法是非常重要的。

**案例2：小学一年级《语文（下册）》——《雪地里的小画家》**
1. 教材分析：本课把数量词分类集中在四幅不同的图画之中，学生在感受美丽景色、感受美好生活的同时，认识事物，认识表示事物的汉字，初步感知不同事物的数量词的表达方式。为本单元的综合练习打下基础。
2. 学情分析：教材的安排形象生动，利于儿童接受和记忆，但对于学生来说，如何在生活中正确使用量词有一定难度，因此在教学本课时创设情境，帮助学生认识事物、学习汉字是学习的关键。

### 教学目标案例

**案例1：初中八年级道德与法治——学生成长中需要处理的关系**
1. 健全人格：通过情景体验合作交流，逐步掌握与他人交往沟通的技能，践行尊重他人诚实守信等优秀品质。
2. 政治认同：了解世界文化的多样性和丰富性，尊重本国的文化和习俗，拥有民族自信心、自豪感。
3. 道德修养：通过参与集体活动，正确认识和处理个人和集体之间的关系，逐渐形成善于合作的个性品质。

**案例2：初中八年级英语**
1. 语言能力：通过课堂听力练习，获取与听力内容有关的五个W一个H信息，提高对信息的理解和判断能力。
2. 文化意识：描述中外有关娱乐饮食等方面的文化差异，开阔视野，丰富思想。
3. 思维能力：能概括文章大意，获取事实性信息，提高阅读理解分析能力。

### 教学内容案例

**案例1：高中化学必修1——铁**
1. 重点：通过分析铁元素价态，会从氧化还原角度分析铁及其化合物的性质
2. 难点：根据研究物质性质的程序设计实验方案，实现铁与铁的化合物的转化，掌握探究物质氧化性或还原性的过程与方法

**案例2：高中物理必修1——匀变速直线运动**
1. 重点：通过实验探究匀变速直线运动的规律
2. 难点：学会用公式和图像表示匀变速直线运动的规律，并能用相关规律解决实际问题

**案例3：高中历史必修1——美国联邦政府的建立**
1. 重点：准确说出美国1787年宪法的主要内容和联邦制的权力结构，理解1787宪法是人类政治智慧的精华
2. 难点：动手设计制作表格，比较美国总统制和英国君主立宪制的异同，加深对民主政治的多样性和各自独特性的认识

### 教学程序案例

**案例1：高中生物必修3《生态系统及其稳定性》**
教学模式：程序性教学、小组合作学习

- 环节1：自主阅读、设计概念图——教师介绍人类面临的资源与环境问题，引出本课题。
- 环节2：观察、讨论，模型建构——学生以小组为单位观察池塘生态系统图解和教师提供的生态瓶，阅读教材互动交流。
- 环节3：知识回顾、自主阅读、展示反馈——教师引领学生对初中知识进行回顾。
- 环节4：总结、梳理、归纳——结合学习目标，师生共同回顾目标达成情况。
- 环节5：课后拓展——课后制作特色生态瓶，作为过程性评价的一部分。

**案例2：初中八年级历史《改革开放》**
教学模式：主要以小组合作学习展开，融入探究式教学

- 环节一：体验情景，预习思考——教师通过情景引入，让学生了解改革之前国家发展现状，引导学生认识到农村改革的必要性和迫切性。
- 环节二：合作探究，理解知识——教师指导学生阅读课文，引导学生小组合作探究，了解家庭联产承包责任制的含义及影响。
- 环节三：调查事件、展示交流——课前分组，让学生调查了解国有企业情况，课上派代表展示调查结果（如粮票、油票等）。
- 环节四：合作探究、分析归纳——指导学生观看反映深圳对外开放巨大变化的视频，引导学生在地图上标出五个经济特区的地理位置，分组讨论，派代表汇报。
- 环节五：总结课程、延伸升华——引导学生对改革开放深入思考，以小论文形式呈现思考结果。

### 教学环境案例

教学环境：为便于小组合作学习与成果展示，班级座位摆放为矩形，分成合作小组的同学面对面，便于交流与合作。

座位摆放形式可选：传统班级授课、环形、马蹄形、矩形、临时兴趣站等。

### 教学评价案例

**高中语文《归去来兮辞》**
1. 随堂测试：写写自己对陶渊明"归隐之乐"复杂情感的认识和评价，并让大家互相批改。
2. 作业布置：
   - 必做作业：①在反复诵读课文的基础上背诵全文。②根据课上同学帮自己批改的作业进行修改和完善。
   - 选做作业：从以下方式中任选一种，写一写"我"心中的陶渊明。①为教材的《陶渊明画像》题一首诗。②在班内作一场有关陶渊明研究的报告。

## 三、教学评价五维度（底层逻辑）

| 维度 | 具体内容 |
|---|---|
| Who 评价主体 | 多主体（教师评价学生、学生之间、学生评价教师等） |
| When 评价时间 | 过程性评价（全程：诊断、过程、终结） |
| Way 评价方式 | 纸笔测验（量）与表现型任务（质） |
| What 评价内容 | 全方位（知识、技能、过程、情感态度价值观等） |
| Why 评价目的 | 发展性评价（通过评价促进学生学习与教师教学） |
